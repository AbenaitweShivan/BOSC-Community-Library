# Contributing to BOSC Community Library

Thank you for your interest in contributing! Follow these steps to get started.

## How to Contribute

### 1. Fork the Repository
- Click the "Fork" button at the top right of this page
- This creates your own copy of the repository

### 2. Clone Your Fork
```bash
git clone https://github.com/YOUR-USERNAME/BOSC-Community-Library.git
cd BOSC-Community-Library
```

### 3. Create a Branch
Always create a new branch for your changes:
```bash
git checkout -b feature/your-feature-name
```

### 4. Make Your Changes
- Keep changes focused and small
- Follow existing file structure and formatting
- Use clear, descriptive commit messages

### 5. Commit and Push
```bash
git add .
git commit -m "describe what you changed"
git push origin feature/your-feature-name
```

### 6. Open a Pull Request
- Go to the original repository
- Click "New Pull Request"
- Describe what your PR does and why

## Reporting Issues
- Use the GitHub Issues tab
- Be as descriptive as possible
- Include steps to reproduce any bugs

## Code Style
- Use proper Markdown formatting
- Keep file names lowercase with hyphens
- Add comments where necessary

## Questions?
Open a GitHub Issue and tag it with the "question" label.
